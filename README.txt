PANCHOO'S BIRTHDAY SURPRISE — QUICK SETUP
==========================================

1. Keep the folder structure as it is:
   Panchoo_Birthday_2026/
     index.html
     style.css
     script.js
     images/
     music/

2. Add your 9 photos:
   Copy your photos into the images folder and rename them exactly:
   photo-1.jpg
   photo-2.jpg
   ...
   photo-9.jpg
   If your photos are PNG, either convert them to JPG or change the matching
   image filename extensions in index.html.

3. Add songs:
   Put your MP3 files inside the music folder and name them:
   song-1.mp3
   song-2.mp3
   song-3.mp3
   You can change song titles and artist names in the `songs` list in script.js.
   Browser autoplay is usually blocked, so the visitor must press Play.

4. Open index.html in Chrome to preview.
   Internet is needed for the Google Fonts. The rest of the site runs locally.

5. Personalize:
   - Edit the love letter directly in index.html.
   - Edit the six reasons in index.html.
   - The countdown is set to 31 October 2026 in script.js.
   - Replace "Your Dilki" if you want a different sign-off.

IMPORTANT:
This is a private local project until you choose to publish or share it.
If you publish it online, anyone with access to the public link may be able to view it.
